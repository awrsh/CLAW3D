# Character models

Free animated GLB characters used by the office sample.

| File | Source / style | Notes |
|------|----------------|-------|
| `mc_steve.glb` | Minecraft-style Steve (via GetGLB / Quaternius-style pack) | Walk / Idle clips |
| `platformer.glb` | Quaternius Animated Platformer Character (CC0) | Walk / Idle |
| `adventurer2.glb` | Adventurer rig (GetGLB) | Walk / Idle |
| `Soldier.glb` | three.js examples Soldier | Walk / Idle / Run |

Original pack folders also live under `object-model/` when you add your own assets.
Do not commit proprietary Mojang textures; these are third-party CC0 / sample assets.
