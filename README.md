# Claw3D Sample (`new-version`)

سمپل مستقل آفیس سه‌بعدی — **بدون Gateway** · پورت **5050**

```bash
cd new-version
npm install
npm run dev
```

---

## قابلیت‌ها

- کف / دیوار محیط / چندطبقه + راه‌پله و ستون
- **ابجکت‌های دقیق old-version**: GLB مبلمان + مدل‌های procedural (آشپزخانه، باشگاه، سرور، …)
- **دیوارهای داخلی متنوع**: ساده، گچی، آجری، شیشه‌ای، پارتیشن + در
- **فضاهای آماده**: مدیرعامل، مدیریت، برنامه‌نویسی، مالی، جلسه، آشپزخانه، **آشپزخانه + مدیریت**
- ابجکت‌ها + درگ + چیدن روی میز + **Ctrl+Z**
- **Snap** به گرید / دیوار
- **Pathfinding** کاراکترها دور دیوار و مبلمان
- **نور روز / عصر / شب** + روشن/خاموش لامپ
- نوتیف و صدای کوتاه برای رویدادهای دفتر

## Tools

1. Snap، نور، لامپ، Mute
2. فضاهای آماده (از جمله آشپزخانه + مدیریت)
3. دیوار / در و ابجکت‌ها
4. کاراکترها
